# VISIONS OS

A personal productivity OS for creative professionals. Built as a single self-contained HTML file — no install, no server, no dependencies.

---

## What it is

VISIONS OS is a daily operating system for solo creatives. It combines:

- **THE QUADRANT** — an energy-state task board with four zones (Locked In / Processing / Cruise / Maintenance). Tasks are placed based on energy, not just priority.
- - **THE RUNWAY** — long-term goal tracking via Arcs. Each Arc tracks progress through linked daily tasks over time.
  - - **DAILIES BANK** — a reusable task library. Tasks are dragged into the Quadrant each day, or marked done/skipped directly.
    - - **DEBRIEF** — a weekly performance snapshot with completion rate, zone behaviour, Arc progress, passive completions, and behavioural notes.
     
      - All data is stored locally in your browser via `localStorage`. No account required.
     
      - ---

      ## How to use

      1. Download `visions-os.html`
      2. 2. Open it in any modern browser (Chrome or Safari recommended)
         3. 3. Double-click the file on your Mac to launch
           
            4. That's it. Everything runs locally.
